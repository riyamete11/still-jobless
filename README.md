# Still Jobless

What 2026 design job descriptions wanted, and what they thought of me. A data story told on a computer older than the AI hype.

## The data

- **Job descriptions:** 378 product, UX and UI design postings from the public Greenhouse, Ashby and Lever job boards of 92 companies, pulled in November 2026. Counted with simple keyword matching. Most were posted September to November 2026, so it's a snapshot, not a trend.
- **My applications:** confirmation and rejection emails in my own inbox, January to November 2026. Only totals and a few company names appear on the page; the raw inbox data stays private.

## Running it

It's a static page. Serve the folder with any static server, for example `npx vite .`
